AOENGINE オブジェクト取得ガイド

シーンに保存されたGameObject、Sprite、Text、およびPrefabをC++コードから取得する方法です。

基本

シーン内のオブジェクトはSceneRendererが持つSceneWorldに登録されています。現在は名前専用の検索関数がないため、GetObjectHandles()で列挙して型と名前を確認します。

1. 共通の名前検索関数

次のテンプレート関数を、シーンのcppまたは共通Utilityへ追加すると便利です。

#include <string>
#include "Engine/Render/SceneRenderer.h"

template<class T>
T* FindSceneObject(const std::string& objectName)
{
    AOENGINE::SceneRenderer* renderer =
        AOENGINE::SceneRenderer::GetInstance();

    if (!renderer) {
        return nullptr;
    }

    for (const AOENGINE::ObjectHandle& handle : renderer->GetObjectHandles()) {
        AOENGINE::SceneObject* object = renderer->FindObject(handle);
        if (!object || object->GetName() != objectName) {
            continue;
        }

        if (T* result = dynamic_cast<T*>(object)) {
            return result;
        }
    }

    return nullptr;
}

2. 保存済みGameObjectを取得する

#include "Engine/Module/Components/GameObject/BaseGameObject.h"

AOENGINE::BaseGameObject* player =
    FindSceneObject<AOENGINE::BaseGameObject>("Player");

if (player) {
    player->GetTransform()->SetTranslate({ 0.0f, 0.0f, 10.0f });
}

シーンのメンバとして保持する場合は、Init()直後ではなく、シーンJSONの読み込みが完了した後に取得する必要があります。現在の構成ではOnPlayStart()で取得する方法が安全です。

class TestScene : public BaseScene {
public:
    void OnPlayStart() override;

private:
    AOENGINE::BaseGameObject* player_ = nullptr; // 非所有ポインタ
};

void TestScene::OnPlayStart()
{
    player_ = FindSceneObject<AOENGINE::BaseGameObject>("Player");
}

3. Spriteを取得する

#include "Engine/Module/Components/2d/Sprite.h"

AOENGINE::Sprite* playerIcon =
    FindSceneObject<AOENGINE::Sprite>("PlayerIcon");

if (playerIcon) {
    playerIcon->SetTranslate({ 100.0f, 100.0f });
}

4. Textを取得する

TextはSpriteの派生型なので、Textとして取得したい場合は必ずText型を指定します。

#include "Engine/Module/Components/2d/Text.h"

AOENGINE::Text* hpText =
    FindSceneObject<AOENGINE::Text>("HpText");

if (hpText) {
    hpText->SetText("HP: 100");
}

5. Prefabをコードから生成して取得する

Instantiate()には拡張子を付けず、Prefab名だけを渡します。

#include "Engine/System/Manager/PrefabManager.h"
#include "Engine/Module/Components/GameObject/BaseGameObject.h"

AOENGINE::SceneObject* prefabRoot =
    AOENGINE::PrefabManager::GetInstance()->Instantiate("Enemy");

AOENGINE::BaseGameObject* enemy =
    dynamic_cast<AOENGINE::BaseGameObject*>(prefabRoot);

if (enemy) {
    enemy->GetTransform()->SetTranslate({ 5.0f, 0.0f, 10.0f });
}

上のコードは次のファイルを読み込みます。

Assets/Game/Prefabs/Enemy.prefab.json

Sprite Prefab

AOENGINE::Sprite* icon = dynamic_cast<AOENGINE::Sprite*>(
    AOENGINE::PrefabManager::GetInstance()->Instantiate("PlayerIcon"));

if (icon) {
    icon->SetTranslate({ 640.0f, 360.0f });
}

6. すでにシーンへ配置されたPrefabを取得する

Hierarchyやシーンファイルから復元されたPrefabもSceneWorld内に存在するので、ルート名で取得できます。

AOENGINE::BaseGameObject* enemy =
    FindSceneObject<AOENGINE::BaseGameObject>("Enemy01");

if (enemy && enemy->IsPrefabInstanceRoot()) {
    const std::string& prefabName = enemy->GetPrefabSource();
    // prefabName == "Enemy"
}

7. 使い分け

目的方法
保存済み3DオブジェクトFindSceneObject<BaseGameObject>("名前")
保存済みSpriteFindSceneObject<Sprite>("名前")
保存済みTextFindSceneObject<Text>("名前")
Prefabを新規生成PrefabManager::Instantiate("Prefab名")
配置済みPrefabルート名で検索後、IsPrefabInstanceRoot()を確認
ポインタの寿命に注意

取得したポインタはSceneWorldが所有する非所有ポインタです。シーン切り替え、シーン再読み込み、Play停止時のスナップショット復元、オブジェクト削除後には無効になります。復元後は名前またはObjectHandleから再取得してください。また、同名オブジェクトが複数ある場合、この検索例は最初の1件を返します。
