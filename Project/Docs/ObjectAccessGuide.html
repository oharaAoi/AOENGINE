AOENGINE オブジェクト操作ガイド

オブジェクトの選び方から、取得・生成、ゲームロジックの分離、Prefab、調整値、寿命管理までを順番に確認できる実用ガイドです。

目的から探す
  • クイックリファレンス
  • 保存済みオブジェクトを取得
  • GameObjectを新規生成
  • BaseEntityでロジックを分離
  • Prefabを生成・取得
  • Custom Parametersを表示
  • 寿命とPlayモードの注意

2. シーンに保存されたオブジェクトを取得する

シーン内のオブジェクトはSceneRendererのSceneWorldに登録されています。次の共通関数をUtilityまたはシーンのcppに用意すると、名前と型で検索できます。

共通検索関数

#include <string>
#include "Engine/Render/SceneRenderer.h"

template<class T>
T* FindSceneObject(const std::string& objectName)
{
    AOENGINE::SceneRenderer* renderer =
        AOENGINE::SceneRenderer::GetInstance();

    if (!renderer) {
        return nullptr;
    }

    for (const AOENGINE::ObjectHandle& handle : renderer->GetObjectHandles()) {
        AOENGINE::SceneObject* object = renderer->FindObject(handle);
        if (!object || object->GetName() != objectName) {
            continue;
        }

        if (T* result = dynamic_cast<T*>(object)) {
            return result;
        }
    }
    return nullptr;
}

GameObject

#include "Engine/Module/Components/GameObject/BaseGameObject.h"

AOENGINE::BaseGameObject* player =
    FindSceneObject<AOENGINE::BaseGameObject>("Player");

if (player) {
    player->GetTransform()->SetTranslate({ 0.0f, 0.0f, 10.0f });
}

Sprite

#include "Engine/Module/Components/2d/Sprite.h"

AOENGINE::Sprite* icon =
    FindSceneObject<AOENGINE::Sprite>("PlayerIcon");

if (icon) {
    icon->SetTranslate({ 100.0f, 100.0f });
}

Text

TextはSpriteの派生型です。Text固有APIを使う場合は必ずText型で検索します。

#include "Engine/Module/Components/2d/Text.h"

AOENGINE::Text* hpText =
    FindSceneObject<AOENGINE::Text>("HpText");

if (hpText) {
    hpText->SetText("HP: 100");
}
推奨タイミング

シーンJSONはシーンのInit()後に読み込まれます。保存済みオブジェクトへの参照取得は、読み込み後に呼ばれるOnPlayStart()で行うのが安全です。

void TestScene::OnPlayStart()
{
    player_ = FindSceneObject<AOENGINE::BaseGameObject>("Player");
    hpText_ = FindSceneObject<AOENGINE::Text>("HpText");
}

3. 通常のGameObjectをコードから生成する

Prefabを使わない場合はSceneRenderer::AddObject()で生成します。返されるポインタは非所有です。

通常Material

#include "Engine/Render/SceneRenderer.h"
#include "Engine/Module/Components/GameObject/BaseGameObject.h"

AOENGINE::SceneRenderer* renderer =
    AOENGINE::SceneRenderer::GetInstance();

AOENGINE::BaseGameObject* enemy =
    renderer->AddObject<AOENGINE::BaseGameObject>(
        "Enemy",
        "Object_Normal.json"
    );

if (enemy) {
    enemy->SetObject("Enemy.gltf");
    enemy->GetTransform()->SetTranslate({ 0.0f, 0.0f, 10.0f });
}

PBR Material

AOENGINE::BaseGameObject* enemy =
    renderer->AddObject<AOENGINE::BaseGameObject>(
        "Enemy",
        "Object_PBR.json"
    );

if (enemy) {
    enemy->SetObject("Enemy.gltf", AOENGINE::MaterialType::PBR);
}

コンポーネント

if (enemy) {
    enemy->SetAnimator();
    enemy->SetPhysics();
    enemy->SetCollider("Default", AOENGINE::ColliderShape::AABB);
}
Inspectorから削除

Collider、RigidBody、Animatorは、Inspectorのコンポーネントヘッダーを右クリックし、Remove Componentを選択すると確認後に削除できます。

親子関係

AOENGINE::BaseGameObject* weapon =
    renderer->AddObject<AOENGINE::BaseGameObject>(
        "Weapon", "Object_Normal.json");

if (enemy && weapon) {
    weapon->SetObject("Weapon.gltf");
    renderer->SetParent(weapon->GetHandle(), enemy->GetHandle());
}

Play開始時に生成

void TestScene::OnPlayStart()
{
    AOENGINE::SceneRenderer* renderer =
        AOENGINE::SceneRenderer::GetInstance();

    enemy_ = renderer->AddObject<AOENGINE::BaseGameObject>(
        "RuntimeEnemy", "Object_Normal.json");

    if (enemy_) {
        enemy_->SetObject("Enemy.gltf");
        enemy_->GetTransform()->SetTranslate({ 0.0f, 0.0f, 10.0f });
    }
}

4. BaseEntityでゲームロジックを分離する

BaseEntityはシーン上のオブジェクトではなく、ゲームロジック用の非所有ラッパーです。PlayerやEnemyを継承させ、SceneWorldが所有するBaseGameObjectとBind()で関連付けます。

役割の分担

BaseGameObjectはTransform・描画・Colliderなどの実体、BaseEntity派生クラスは移動・HP・攻撃などのゲームロジックを担当します。

Playerクラスを作る

#pragma once
#include "Engine/Module/Components/GameObject/BaseEntity.h"

class Player : public AOENGINE::BaseEntity {
public:
    void Update();
    void Damage(float amount);

private:
    float hp_ = 100.0f;
};
#include "Player.h"
#include "Engine/Module/Components/GameObject/BaseGameObject.h"
#include "Engine/Module/Components/WorldTransform.h"

void Player::Update()
{
    // ObjectHandleの解決は配列インデックスによるO(1)アクセス。
    // 同じフレーム内では一度取得したポインタを使い回す。
    AOENGINE::BaseGameObject* object = GetGameObject();
    if (!object) {
        return;
    }

    AOENGINE::WorldTransform* transform = object->GetTransform();
    // transformを使って移動処理
}

void Player::Damage(float amount)
{
    hp_ -= amount;
    if (hp_ <= 0.0f) {
        Destroy();
    }
}

配置済みPlayerへ関連付ける

Editorで配置してシーンへ保存したGameObjectは、Play開始時に名前で取得して関連付けます。

void GameScene::OnPlayStart()
{
    AOENGINE::BaseGameObject* playerObject =
        FindSceneObject<AOENGINE::BaseGameObject>("Player");

    player_.Bind(playerObject);
}

コード生成したPlayerへ関連付ける

AOENGINE::SceneRenderer* renderer =
    AOENGINE::SceneRenderer::GetInstance();

AOENGINE::BaseGameObject* playerObject =
    renderer->AddObject<AOENGINE::BaseGameObject>(
        "Player", "Object_Normal.json");

if (playerObject) {
    playerObject->SetObject("Player.gltf");
    player_.Bind(playerObject);
}

よく使う操作

API用途
Bind(object)登録済みGameObjectと関連付ける
IsValid()関連付けたGameObjectが存在するか確認する
GetGameObject()BaseGameObjectを安全に取得する
GetTransform()Transformを取得する。無効時はnullptr
GetCollider(name)指定名のColliderを取得する
SetIsActive(bool)関連付けたGameObjectのActiveを変更する
SetRendering(bool)3D描画の有効・無効を変更する
SetParent(parent)別のBaseEntityが参照するGameObjectの子にする
MoveToRoot()親子関係を解除してシーン直下へ戻す
Destroy()GameObjectと子階層を削除し、自身の関連付けも解除する
Unbind()GameObjectを削除せず関連付けだけ解除する
BaseEntityはGameObjectを所有しません

GetGameObject()で得たポインタをdeleteしないでください。削除にはDestroy()を使います。また、BaseEntity自体はHierarchyやシーンJSONには保存されません。

Play停止・シーン再読み込み後は再Bind

Play停止時のスナップショット復元やシーン切り替えではObjectHandleが無効になります。次回のOnPlayStart()で対象を取得し直してBind()してください。

5. Prefabを扱う

保存先Assets/Game/Prefabs/

Prefabをコードから生成

拡張子を付けず、Prefab名だけを指定します。

#include "Engine/System/Manager/PrefabManager.h"

AOENGINE::SceneObject* root =
    AOENGINE::PrefabManager::GetInstance()->Instantiate("Enemy");

AOENGINE::BaseGameObject* enemy =
    dynamic_cast<AOENGINE::BaseGameObject*>(root);

if (enemy) {
    enemy->GetTransform()->SetTranslate({ 5.0f, 0.0f, 10.0f });
}

上のコードはAssets/Game/Prefabs/Enemy.prefab.jsonを読み込みます。

Sprite Prefab

AOENGINE::Sprite* icon = dynamic_cast<AOENGINE::Sprite*>(
    AOENGINE::PrefabManager::GetInstance()->Instantiate("PlayerIcon"));

if (icon) {
    icon->SetTranslate({ 640.0f, 360.0f });
}

配置済みPrefabを取得

AOENGINE::BaseGameObject* enemy =
    FindSceneObject<AOENGINE::BaseGameObject>("Enemy01");

if (enemy && enemy->IsPrefabInstanceRoot()) {
    const std::string& source = enemy->GetPrefabSource();
    // source == "Enemy"
}

エディター操作

  1. HierarchyのGameObjectをAssets上部のPrefabドロップ領域へ落とすとPrefabを作成できます。
  2. *.prefab.jsonをAssetsからScene Viewへ落とすと、シーンへ配置できます。
  3. 3DはY=0平面、Sprite／TextはCanvas上のドロップ位置へ配置されます。
現在のPrefab Override

シーン固有情報として保存されるのは、Prefabルートの名前、Active、Transformです。子オブジェクトや内部コンポーネントの個別変更は、現段階では差分保存されません。

6. Custom ParametersをImGuiへ表示する

CustomParameterSetを継承した構造体を作ると、InspectorRegistryへの個別登録なしで専用ウィンドウへ表示できます。

パラメータ構造体

#include <string>
#include "Engine/System/Editor/Parameter/CustomParameter.h"

struct PlayerParameters : public AOENGINE::CustomParameterSet {
    PlayerParameters()
        : CustomParameterSet("Player")
    {
        AddParameter("HP", hp, 1.0f, 0.0f, 100.0f);
        AddParameter("Max HP", maxHp, 1.0f, 1.0f, 1000.0f);
        AddParameter("Move Speed", moveSpeed, 0.1f, 0.0f, 100.0f);
        AddParameter("Invincible", invincible);
        AddParameter("Spawn Position", spawnPosition, 0.1f);
        AddParameter("Player Color", playerColor);
        AddParameter("Display Name", displayName);
    }

    float hp = 100.0f;
    float maxHp = 100.0f;
    float moveSpeed = 5.0f;
    bool invincible = false;
    Math::Vector3 spawnPosition{};
    AOENGINE::Color playerColor = Colors::Linear::white;
    std::string displayName = "Player";
};

Playerクラスへ組み込む

class Player {
public:
    void Update()
    {
        if (parameters_.hp <= 0.0f) {
            // 死亡処理
        }
    }

private:
    PlayerParameters parameters_;
};

構造体の生成時に管理者へ自動登録され、破棄時に自動解除されます。閉じたウィンドウはSetting → Custom Parametersから再表示できます。

AddParameterの数値指定

AddParameter("HP", hp, 1.0f, 0.0f, 100.0f)は、順に「変数」「操作速度」「最小値」「最大値」です。最小値と最大値が両方0なら範囲制限なしです。

7. 寿命とPlayモードの注意点

SceneWorldが所有します

AddObject()、Instantiate()、名前検索で得たポインタを呼び出し側でdeleteしないでください。すべて非所有ポインタです。

再読み込み後は再取得します

シーン切り替え、シーン再読み込み、Play停止時のスナップショット復元、オブジェクト削除後には、以前のポインタが無効になります。名前または新しいObjectHandleから再取得してください。

名前の重複

このガイドのFindSceneObject()は、同じ名前が複数ある場合に最初の1件を返します。一意な名前を使うか、必要に応じて複数件を返す検索関数を用意してください。

Custom Parameterの参照先

AddParameter()には構造体のメンバ変数を渡してください。コンストラクタ内のローカル変数や、構造体より先に破棄される外部変数は登録できません。

基本の選択

実体はシーン・Prefab・AddObject()で管理し、ゲームロジックはBaseEntityへ分離します。繰り返し生成はInstantiate()、ゲーム固有の調整値はCustom Parametersを使うと責務を整理できます。
